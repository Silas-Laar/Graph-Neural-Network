# Graph-Neural-Network
Developing a physics-informed graph neural network integrating hydraulic data and GIS shapefiles to predict urban floodwater levels across interconnected underground drainage and surface-water networks.
Incorporating rainfall, terrain elevation, drainage connectivity, water flow, and conservation constraints to improve prediction consistency and identify potential flood hotspots.
Developing geospatial flood-risk visualizations to explore applications in urban flood early warning and humanitarian disaster preparedness.
